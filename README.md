# عيادة د. عادل عمار آدم — Clinic Website

موقع عيادة متخصص في أمراض النساء والولادة للدكتور **عادل عمار آدم**، يتضمن صفحة رئيسية
طبية أنيقة ونظام حجز مواعيد إلكتروني كامل. الموقع باللغة العربية بالكامل مع دعم اتجاه
الكتابة من اليمين لليسار (RTL)، وبُنيت بنيته بحيث يسهل إضافة الإنجليزية لاحقًا.

هذه هي المرحلة الأولى من مشروع أكبر لبناء نظام إدارة عيادة متكامل (حجز، ملفات مرضى،
لوحة تحكم إدارية، متابعات، تذكيرات). التفاصيل الكاملة لبقية المراحل موجودة في
[`PLAN.md`](./PLAN.md).

## الصفحات الحالية

- **الصفحة الرئيسية (`/`)** — تعريف بالطبيب، خدمات العيادة، لماذا تختارين عيادتنا،
  مواعيد العمل، معلومات التواصل والموقع، الأسئلة الشائعة.
- **حجز موعد (`/booking`)** — تدفق حجز كامل: اختيار التاريخ والوقت المتاح، تعبئة بيانات
  المريضة، مراجعة الملخص وسياسة المواعيد مع رمز تحقق (CAPTCHA)، ثم شاشة تأكيد برقم حجز
  فريد.

> ملاحظة: جميع بيانات التواصل (الهاتف، واتساب، البريد، العنوان) والمؤهلات العلمية
> ومواعيد العمل معروضة حاليًا كحقول نائبة (placeholders) واضحة، لأن هذه المعلومات لم
> تُقدَّم بعد. ستُدار هذه الحقول من لوحة تحكم العيادة في مرحلة قادمة.

## التقنيات المستخدمة

| الطبقة | التقنية |
|---|---|
| إطار العمل | TanStack Start |
| الواجهة | React 19 + TanStack Router |
| البناء | Vite 7 |
| التنسيق | Tailwind CSS 4 |
| الأيقونات | lucide-react |
| اللغة | TypeScript (strict mode) |
| الاستضافة | Netlify |

الصور التوضيحية (الرسوم الطبية في الصفحة الرئيسية) تم توليدها عبر Netlify AI Gateway
(Gemini image model) وتُعرض عبر Netlify Image CDN لتحسين الأداء.

## التشغيل محليًا

```bash
pnpm install
pnpm dev
```

أو عبر Netlify CLI لمحاكاة كامل بيئة Netlify (الدوال، الصور، إلخ):

```bash
netlify dev
```
